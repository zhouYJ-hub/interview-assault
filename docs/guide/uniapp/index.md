# UniApp 专题概览

> 面试频率：⭐⭐⭐⭐（小程序/跨端岗位必考）| 20 道核心题，按「基础 -> 进阶 -> 高级」三篇组织

## 面试回答示范（总-分结构）

> **总起**：uni-app 是用 Vue 语法开发多端应用的框架——一套代码编译到 H5、各家小程序和 App，我从基础、进阶、高级三个层面讲。
>
> **第一，基础层面。** 掌握三层生命周期和执行顺序、五种跳转方式的区别、页面通信的四种手段、rpx 响应式单位的换算原理。
>
> **第二，进阶层面。** 熟练做条件编译处理平台差异、封装 uni.request 拦截器（token/loading/401 统一处理）、用 Pinia 做持久化状态管理、完整实现过微信登录和支付的闭环流程。
>
> **第三，高级层面。** 会配置分包解决主包 2M 限制、实现过 App 端 wgt 热更新（版本比对 -> 下载 -> 安装 -> 重启）、了解虚拟列表等长列表性能优化和多端差异化处理。

## 速记卡

```text
1. 跨端两支柱：统一 API 层 + 条件编译
2. 生命周期三层：App -> 页面(onLoad/onShow/onReady) -> 组件(Vue)
3. 跳转：navigateTo 入栈可返回；switchTab 专跳 tabbar 不带参
4. 通信四式：URL / EventChannel / uni.$emit / 状态管理
5. rpx 按 750 设计稿等比：750rpx = 屏幕宽
6. 分包解决主包 2MB；热更新 wgt 只更新前端资源
7. 登录 code 后端换 openid；支付以后端回调为准
```
